# MediTrack – Medicine Reminder & Tracking Website

## About
MediTrack is a web-based application that helps users manage medicine schedules, receive reminders, and track their medication history.

## Project Objective
To simplify medication management by providing timely reminders, organized medicine schedules, and tracking of taken and missed doses.

## Features
- User registration and login
- Add, update, and delete medicines
- Medicine schedules and reminders
- Calendar view for medication planning
- Track taken and missed medicines
- Notifications and medication history
- Charts and reports for tracking medication patterns
- User profile management

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Tools:** XAMPP, Visual Studio Code
- **Charts:** Chart.js

## Installation and Setup
1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project folder in Visual Studio Code.
3. Install [Node.js](https://nodejs.org/) and [XAMPP](https://www.apachefriends.org/).
4. Start MySQL using XAMPP.
5. Configure the database connection according to your project settings.
6. Install the required dependencies:
   ```bash
   npm install
   ```
7. Start the application using the command specified in your project configuration.

## Database
MySQL stores user details, medicine information, medication history, and notifications in structured tables.

## Future Enhancements
- Mobile application support
- SMS and email reminders
